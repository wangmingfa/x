# 2026-10-01 · P3 窗口域（三平台）

新增 `x window list` / `active` / `focus|minimize|maximize <序号或标题>`。
核心模型 `x-core/src/window.rs`，适配器：Windows 走 `windows/window.rs`
的 user32 原生枚举与动词，Linux/macOS 走 `common/window_os.rs`。审计
装饰器在组合根挂 `window.focus` / `window.minimize` / `window.maximize`
三类动作，target 取 `WindowInfo::label()`（标题优先，退化到 id / 无名）。

## 决策

**Windows 全量原生，不加壳。** `EnumWindows` + 回调收集 `HWND`（filter
在回调里做可见性判断，少一次跨调用），`GetWindowTextW` 取标题（UTF-16
直转 `String::from_utf16_lossy`）、`GetWindowThreadProcessId` 关联进程、
`OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION)` + `QueryFullProcess
ImageNameW` 取可执行名（受限权限即可问，不必提权）。列表过滤「可见 +
标题非空」：user32 里常驻大量消息窗/宿主窗，不过滤则清单九成是噪声，
这是有意的实用主义，模块文档里写明。

**前台锁拒绝 = 如实报错，不假装成功。** `SetForegroundWindow` 返回
`FALSE`（前台锁被别的进程持有）时报 InvalidState，附可操作说明
（「重试，或先点一下目标窗口」）。最小化过的窗口先 `SW_RESTORE` 再
置顶，一步到位；失败时错误信息带着目标名，调用者知道是谁没成功。

**macOS 两段式：免权限读，按需动词。** 列窗口走手中声明的
`CGWindowListCopyWindowInfo`（`#[link(name = "CoreGraphics", kind =
"framework")]`，不引 core-graphics crate——core-foundation 已在树里，
CFArray/CFDictionary/CFNumber/CFString 直接复用）。它免权限，但未授
「屏幕录制」时 `kCGWindowName` 缺席——标题如实留 `None`，不拿进程名
冒充。动词与 active 走 `osascript` System Events：未授「辅助功能」的
拒绝（错误码 -1719 / -25211、文本含 "assistive access"）映射成
`permission_denied(Elevated)`，其余 stderr 原样透出。这个读写权限
不对等是平台事实，如实呈现。

**Linux 借力 wmctrl/xprop，不手撕 X11 协议。** `wmctrl -lp` 一行一窗
（id / 桌面 / pid / host / 标题，标题可能含空格所以是「剩余全部」），
`xprop -root _NET_ACTIVE_WINDOW` 读前台，`xprop -id … _NET_WM_STATE`
读 `_HIDDEN` / `_MAXIMIZED_VERT|HORZ`。`DISPLAY` 未设（纯控制台）或
工具缺失都如实 Unsupported，后者附安装提示。Wayland 没有 EWMH，
wmctrl 本身跑不起来——同样走这条路径，不硬造。

**id 规范化堵住补零分歧。** wmctrl 报 `0x04a00007` 式补零，xprop 报
`0x4a00007` 无补零，同一个窗口两个字符串。统一规范成 `0x{:08X}`
（大写、恰好 8 位）后两边可比；Windows 侧 `format!("0x{:X}")` 同理
规范化（HWND 本来就是数值，不存在源分歧，但显示口径一致）。

**目标选取与 display 同规格。** 1 起序号（0 报 InvalidInput，越界报
NotFound）；名称先精确（忽略大小写）再子串，歧义报 InvalidInput 并
列出候选。动词前从新鲜 `windows()` 重取列表——列表可能已过期，按
旧行号动手是耍流氓。

## 验证

- 单测：core 4（JSON 缺席、往返、label 退化顺序、无后端动词 7）、
  platform 9（Windows 3：id 往返/坏 id 拒/活体枚举不撒谎；common 6：
  wmctrl 行拆分、双补零归一、active 行解析、state 原子、osascript
  输出映射、AppleScript 字面量转义）、audit 1（动词留痕读不留痕）、
  CLI 7（破折号行、JSON 缺席、active 跟随、动词解析+记录、确认拒绝、
  歧义/越界/零、无能力 7）。
- 三 target 交叉 clippy 全绿。
- 本机活体：`window list` 中文标题（设置 / Windows 输入体验）正确
  呈现，active 行唯一；`window active` 表格 + JSON 两口径一致；
  `X_AUDIT_PATH` 沙箱里 minimize + focus「Windows PowerShell」均 ok，
  审计恰好两行，list/active 不落行；随后 focus 把窗口还原回前台。
