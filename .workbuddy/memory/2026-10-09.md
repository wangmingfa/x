## x 项目 Windows 安装失败修复
- 症状：README 的 `irm .../install-release.ps1|iex` 报 `installer did not produce C:\Users\11048490\AppData\Local\x\x.exe`。
- 根因：`Packaging/Windows/x.iss` 旧配置 `DefaultDirName={autopf}\x` + `PrivilegesRequired=admin`（装到 Program Files 且要管理员），而 `scripts/install-release.ps1` 检测的是 `LocalAppData\x` 且未提权启动安装器 → 路径不匹配 + 无权限。
- 修复：`.iss` 改为 `DefaultDirName={localappdata}\x`、`PrivilegesRequired=lowest`，PATH 写入从 HKLM 改 HKCU（用户级），`path` 任务设 `checkedonce`；`.ps1` 显式传 `/DIR="%LOCALAPPDATA%\x"` + `/SUPPRESSMSGBOXES`。
- 注意：已发布的 v0.1.0-rc.1 资产仍是旧逻辑，一行命令要等下次带修复的 release 才免提权开箱即用；临时绕过见对话里的手动安装命令。
- CI（`release.yml`）只传 MyAppVersion/ReleaseTag 给 iscc，不受此次改动影响。
